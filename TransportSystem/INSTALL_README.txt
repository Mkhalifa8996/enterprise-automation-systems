═══════════════════════════════════════════════════════════════════════════════
الطريقة الأولى: بناء ملف EXE مستقل (مُوصى به)
═══════════════════════════════════════════════════════════════════════════════

1. انقر مزدوجاً على ملف: build_exe.bat
2. انتظر حتى تنتهي عملية البناء (قد تستغرق 5-10 دقائق)
3. بعد الانتهاء، ستجد الملف التنفيذي في:
   dist\TransportApp.exe
4. يمكنك نسخ هذا الملف إلى سطح المكتب أو أي مكان آخر
5. انقر مزدوجاً على الملف للتشغيل!

═══════════════════════════════════════════════════════════════════════════════
الطريقة الثانية: تشغيل سريع (بدون بناء)
═══════════════════════════════════════════════════════════════════════════════

1. تأكد من تثبيت Python على جهازك
2. انقر مزدوجاً على ملف: run_app.bat
3. سيتم تثبيت المتطلبات تلقائياً وتشغيل البرنامج

═══════════════════════════════════════════════════════════════════════════════
الطريقة الثالثة: التشغيل اليدوي
═══════════════════════════════════════════════════════════════════════════════

افتح Command Prompt أو PowerShell في مجلد البرنامج ونفذ:

    pip install -r requirements.txt
    python main.py

═══════════════════════════════════════════════════════════════════════════════
المتطلبات الأساسية
═══════════════════════════════════════════════════════════════════════════════

- Windows 7/8/10/11
- Python 3.8 أو أحدث (للتشغيل من المصدر)
- مساحة فارغة: 100 ميجابايت على الأقل

═══════════════════════════════════════════════════════════════════════════════
ملاحظات مهمة
═══════════════════════════════════════════════════════════════════════════════

- البيانات محفوظة في: transport_data.db
- النسخ الاحتياطية: transport_data.xlsx و transport_data_backup.xlsx
- إعدادات Firebase: سيظهر حوار لإدخالها عند التشغيل الأول (يتم حفظها في firebase_sync_config.json)
- كلمة مرور المدير: محددة في ملف .env (اختياري - إذا لم يتم تعيينها سيتم إنشاء واحدة عشوائية)

═══════════════════════════════════════════════════════════════════════════════
استكشاف الأخطاء وإصلاحها
═══════════════════════════════════════════════════════════════════════════════

إذا لم يعمل البرنامج:

1. تأكد من تثبيت Python:
   افتح Command Prompt واكتب: python --version

2. تأكد من تفعيل "Add to PATH" أثناء تثبيت Python

3. إذا ظهرت رسالة "Module not found":
   نفذ: pip install openpyxl python-dotenv Pillow

4. إذا استمرت المشكلة:
   احذف مجلد __pycache__ وأعد المحاولة
